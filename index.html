Persamaan Fungsi Keanggotaan (Bab 3.2)

A. Suhu Ruangan (x dalam [16, 36] °C, Ideal K3: 23-26 °C)

Dingin [16, 16, 20, 24]: 1 (x <= 20); (24-x)/4 (20 < x < 24); 0 (x >= 24)

Nyaman [20, 24, 28]: (x-20)/4 (20 < x <= 24); (28-x)/4 (24 < x < 28)

Panas [24, 28, 36, 36]: (x-24)/4 (24 < x < 28); 1 (x >= 28)

B. Tingkat Kebisingan (y dalam [30, 100] dB, Ideal K3: <= 55-65 dB)

Tenang [30, 30, 45, 65]: 1 (y <= 45); (65-y)/20 (45 < y < 65); 0 (y >= 65)

Sedang [45, 65, 85]: (y-45)/20 (45 < y <= 65); (85-y)/20 (65 < y < 85)

Bising [65, 85, 100, 100]: (y-65)/20 (65 < y < 85); 1 (y >= 85)

C. Intensitas Pencahayaan (z dalam [0, 600] Lux, Ideal K3: >= 300 Lux)

Redup [0, 0, 150, 300]: 1 (z <= 150); (300-z)/150 (150 < z < 300); 0 (z >= 300)

Cukup [150, 300, 450]: (z-150)/150 (150 < z <= 300); (450-z)/150 (300 < z < 450)

Terang [300, 450, 600, 600]: (z-300)/150 (300 < z < 450); 1 (z >= 450)

D. Skor Kenyamanan Ruang Kerja (w dalam [0, 100])

Tidak Nyaman [0, 0, 25, 50]: 1 (w <= 25); (50-w)/25 (25 < w < 50)

Cukup Nyaman [25, 50, 75]: (w-25)/25 (25 < w <= 50); (75-w)/25 (50 < w < 75)

Sangat Ideal [50, 75, 100, 100]: (w-50)/25 (50 < w < 75); 1 (w >= 75)
