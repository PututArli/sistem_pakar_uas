Persamaan Fungsi Keanggotaan (Bab 3.2)

A. Kecepatan Wi-Fi (x dalam [0, 100] Mbps)

Lambat [0, 0, 10, 30]: 1 (x ≤ 10); (30-x)/20 (10 < x < 30); 0 (x ≥ 30)

Sedang [10, 30, 50]: (x-10)/20 (10 < x ≤ 30); (50-x)/20 (30 < x < 50)

Cepat [30, 50, 100, 100]: (x-30)/20 (30 < x < 50); 1 (x ≥ 50)

B. Tingkat Kebisingan (y dalam [30, 100] dB)

Tenang [30, 30, 45, 65]: 1 (y ≤ 45); (65-y)/20 (45 < y < 65); 0 (y ≥ 65)

Sedang [45, 65, 85]: (y-45)/20 (45 < y ≤ 65); (85-y)/20 (65 < y < 85)

Bising [65, 85, 100, 100]: (y-65)/20 (65 < y < 85); 1 (y ≥ 85)

C. Harga Rata-rata Menu (z dalam [10, 100] Ribu Rp)

Murah [10, 10, 25, 45]: 1 (z ≤ 25); (45-z)/20 (25 < z < 45); 0 (z ≥ 45)

Sedang [25, 45, 65]: (z-25)/20 (25 < z ≤ 45); (65-z)/20 (45 < z < 65)

Mahal [45, 65, 100, 100]: (z-45)/20 (45 < z < 65); 1 (z ≥ 65)

D. Skor Kecocokan WFC (w dalam [0, 100])

Tidak Disarankan [0, 0, 25, 50]: 1 (w ≤ 25); (50-w)/25 (25 < w < 50)

Cocok untuk Santai [25, 50, 75]: (w-25)/25 (25 < w ≤ 50); (75-w)/25 (50 < w < 75)

Sangat Ideal [50, 75, 100, 100]: (w-50)/25 (50 < w < 75); 1 (w ≥ 75)
